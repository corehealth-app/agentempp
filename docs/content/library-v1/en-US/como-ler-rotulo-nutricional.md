The label on packaged food helps you compare products and log what you ate more accurately. In Brazil, the current nutrition labeling rules were set by Anvisa in RDC 429/2020 and IN 75/2020.

## The nutrition information table

The table shows values in two ways:

- **Per 100 g or 100 ml.** Use it to compare different products on the same basis.
- **Per serving.** It shows how much is in one reference serving, next to the number of servings in the package.

Per-serving values apply only to that amount. If you eat twice as much, the numbers double too.

## The magnifier on the front of the package

Some products show a magnifier symbol on the front. It flags high levels of **added sugars**, **saturated fat** or **sodium**. It is a quick warning for comparing options on the shelf.

## Using this when you log

1. Check the serving size and compare it with what you actually ate.
2. Log the amount you had, not the serving on the label.
3. If you photograph the label, check the values during review before confirming.
