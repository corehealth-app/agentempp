## Preview env attempt and terminal STOP

Current authenticated Vercel OpenAPI accepts an array batch and explicitly
supports `sensitive`. A temporary root-only executor used `O_NOFOLLOW`
descriptors, exact file/value fingerprints, exactly three allowed names, a
minimal child environment and JSON stdin. It never referenced the primary
source and never printed a value.

The initial local pathname invocation failed before opening the staging source
or reaching Vercel because a JavaScript file without shebang was interpreted as
shell. Env readback remained zero, so the remote batch budget remained `0/1`.
The unchanged syntax-checked executor was then invoked explicitly with Node.
That single real Vercel batch attempt returned client exit 1 and executor exit
78; only the sanitized diagnostic fingerprint was emitted.
