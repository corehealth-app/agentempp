**Goal:** Create the first native BodyFlow iOS app as a buildable, testable SwiftUI scaffold with five stable tabs, independent typed navigation, deterministic mocks, explicit screen states, previews, and simulator evidence.

**Architecture:** A single native Xcode app target owns a SwiftUI shell with one <code>NavigationStack</code> per tab. Immutable protocol-typed dependencies enter through one environment value; actor-backed in-memory implementations provide the complete local runtime. Feature roots consume small server-shaped fixtures and render backend-provided values without calculating health or nutrition data.

**Tech Stack:** Xcode 26.6, Swift 6.0 language mode with complete concurrency checking, SwiftUI, Observation, Swift Testing for unit tests, XCTest/XCUIAutomation for UI tests, iOS 18.0 deployment target, iPhone 17 Pro simulator on iOS 26.5.

- [ ] **Step 7: Implement the minimal router**

Use one observable dictionary containing five arrays:

~~~swift
@MainActor
@Observable
final class AppRouter {
    private var paths = Dictionary(
        uniqueKeysWithValues: AppTab.allCases.map { ($0, [AppRoute]()) }
    )
    var presentedSheet: AppSheet?

    func path(for tab: AppTab) -> [AppRoute] {
        paths[tab, default: []]
    }

    func binding(for tab: AppTab) -> Binding<[AppRoute]> {
        Binding(
            get: { self.path(for: tab) },
            set: { self.paths[tab] = $0 }
        )
    }

    func navigate(to route: AppRoute, in tab: AppTab) {
        paths[tab, default: []].append(route)
    }

    func popToRoot(in tab: AppTab) {
        paths[tab] = []
    }
}
~~~

The route stores only <code>AppTab</code> plus lightweight string IDs. The sheet ID maps meal/training/weight/hydration to <code>refeicao</code>, <code>treino</code>, <code>peso</code>, and <code>hidratacao</code>.

~~~swift
enum HTTPMethod: String, Hashable, Sendable {
    case get = "GET"
    case post = "POST"
    case patch = "PATCH"
    case delete = "DELETE"
}

struct APIRequestKey: Hashable, Sendable {

    let path: String
}

struct APIRequest<Response: Decodable & Sendable>: Sendable {
    let method: HTTPMethod
    let path: String
    var key: APIRequestKey { APIRequestKey(method: method, path: path) }
}

protocol APIClient: Sendable {
    func send<Response: Decodable & Sendable>(
        _ request: APIRequest<Response>
    ) async throws -> Response
}
~~~
